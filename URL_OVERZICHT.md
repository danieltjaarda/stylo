## 📝 URL Naamgevingsconventies

### ✅ Gevolgde Conventies

1. **Alle lowercase**
   - ✅ `/bureaustoelen`
   - ❌ `/BureauStoelen`

2. **Koppeltekens voor spaties**
   - ✅ `/verstelbare-bureaus`
   - ❌ `/verstelbare_bureaus`

3. **Nederlandse termen**
   - ✅ `/over-ons`
   - ❌ `/about-us`

4. **Geen trailing slash**
   - ✅ `/contact`
   - ⚠️ `/contact/` (wordt redirect)

5. **Geen file extensions**
   - ✅ `/privacy`
   - ❌ `/privacy.html`

### 🔄 Redirects Checklist

Zorg dat deze redirects bestaan:
- [ ] `www.deskna.nl` → `deskna.nl`
- [ ] URLs met trailing slash → zonder
- [ ] Old URLs (indien van toepassing)
- [ ] Uppercase URLs → lowercase
